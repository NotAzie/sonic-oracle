# YouTube Song Fame Finder v2

Discover true YouTube viral tracks by analyzing re-uploads across edits, AMVs, memes, and slowed+reverb audio.

## Quickstart (Demo Mode - No API Key Needed)
```bash
python main.py --demo
```

## Production Run
```bash
export YOUTUBE_API_KEY="AIza..."
python main.py --start-year 2015 --end-year 2020
```
